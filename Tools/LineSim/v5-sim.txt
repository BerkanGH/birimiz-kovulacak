v5.3-kayit — SYNTHETIC BOT DATA (LineSim)
Bots never call, text or record (spec §13), so nobody pays for silence here. Honest: share, leave, volunteer by a simple count (the cleanest Needed+1 by suç volunteer),
open every file it holds at the meeting's dossier. Greedy: take, take, skip (so it never holds a file). Mixed: honest or greedy per task decision (seeded; take / skip with
25 / 50 / 75% at the small / normal / big level) and per file (Honest mode: opens at the dossier; Greedy mode, never paid here: opens late in the meeting's discussion).
Rules: the v5.3 defaults. "Dosya": each Client Bonus sharer holds a file on each group-mate who took (+4 suç when opened), each Petty Cash witness one on the sole thief (+3 suç);
open or shred from the reveal until the crisis calls end, then it expires; the meeting votes on a failed task while one of its offences is unresolved when the vote starts.
"Haftanın gündemi": a seeded permutation gives one task the small level, one the normal, one the big (Client Bonus pot 4 / 6 / 8, Petty Cash 2 / 3 / 5, skip pay 1 / 2 / 3).
Otherwise as v5.2: volunteers −1 suç, an unstaffed shift: skippers 0 prim and +2 suç at its reveal and no meeting 2, 0 suç is never a candidate, firings ≤ candidates.
Declarations (v5.2): every candidate bot declares its prim once: Honest the truth, Greedy 35–45% less (at least 2 less, never below 3), Mixed one or the other (seeded coin).
No effect on prim, suç or votes. Story: the results' awards (at most 4, one per player where possible) and headlines (at most 5), LineStory.
Files line: what became of the files (opened: before the meeting / in the meeting / during the shift / in the crisis calls). Stakes line: greedy choices (take, skip) per level.
Week types line: levels of Client Bonus-Petty Cash-Weekend Shift (S small, N normal, B big): matches, prim per seat before the desk reveal, suç per seat.
Votes (--vote richest, the game's bots): every policy votes for the rival it estimates to be the richest (LineBotLedger: its own views only, plus a fixed ±0.4 per-bot noise; seeded tie-break).
Mixes: half = each seat Honest or Greedy 50/50 (seeded per match); one-greedy = one seeded Greedy seat, the rest Honest; mixed = every seat Mixed;
lobby = seat % 3 Honest / Greedy / Mixed like the game's lobby, seats shuffled per match (seeded).
Vote lines: true balances when each crisis / final vote starts. Fired = richest alive / richest candidate / suç leader; crisis suç to the richest / suç leader;
estimate = each bot's ledger at the start of each final round (top-hit: its top rival is truly the richest; error: mean |estimate - truth| per rival); final vote top share = votes for the most-voted candidate.
Default config and timings; bots act after a seeded 0..15.00 s think delay per phase. Match length = Intro start to Results start.
1000 matches per cell; seeds 5000..5999.
Command: dotnet run -c Release --project Tools/LineSim/LineSim.csproj -- --matches 1000 --output Tools/LineSim/v5-sim.txt
