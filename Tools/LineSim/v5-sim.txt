v5.1-kayit — SYNTHETIC BOT DATA (LineSim)
Bots never call, text or record (spec §13), so nobody pays for silence here. Honest: share, leave, volunteer by a simple count (the cleanest Needed+1 by suç volunteer),
punish whenever eligible (whistle as a witness, investigate a Client Bonus partner who took). Greedy: take, take, skip; punish only when paid (never here).
Mixed: honest or greedy per task decision (50/50, seeded) and per punishment (Honest or Greedy mode, seeded coin).
Rules: the v5.1 defaults (Client Bonus 3/3, free sharer-only investigation +4 suç, free whistle +3 suç and the thief keeps the cash, volunteers −1 suç,
an unstaffed shift: skippers 0 prim and +2 suç with no meeting 2 vote, 0 suç is never a candidate, firings ≤ candidates).
Votes (--vote richest, the game's bots): every policy votes for the rival it estimates to be the richest (LineBotLedger: its own views only, plus a fixed ±0.4 per-bot noise; seeded tie-break).
Mixes: half = each seat Honest or Greedy 50/50 (seeded per match); one-greedy = one seeded Greedy seat, the rest Honest; mixed = every seat Mixed;
lobby = seat % 3 Honest / Greedy / Mixed like the game's lobby, seats shuffled per match (seeded).
Vote lines: true balances when each crisis / final vote starts. Fired = richest alive / richest candidate / suç leader; crisis suç to the richest / suç leader;
estimate = each bot's ledger at the start of each final round (top-hit: its top rival is truly the richest; error: mean |estimate - truth| per rival); final vote top share = votes for the most-voted candidate.
Default config and timings; bots act after a seeded 0..15.00 s think delay per phase. Match length = Intro start to Results start.
1000 matches per cell; seeds 5000..5999.
Command: dotnet run -c Release --project Tools/LineSim/LineSim.csproj -- --matches 1000 --output Tools/LineSim/v5-sim.txt
