# Art & Asset Pipeline

All 3D assets are generated by Python scripts run in Blender 5.2 headless (Blender MCP was not connected to the
development session, so the same work was done through Blender's Python API — every asset is reproducible from
source). Editable sources: `Art/Blender/*.blend`. Exports: `Art/Export/**.fbx` (archive copy) and
`Game/Assets/Game/Art/Models/**.fbx` (imported by Unity).

```
blender -b --factory-startup -P Art/Scripts/build_characters.py -- --previews
blender -b --factory-startup -P Art/Scripts/build_props.py -- --previews --each
blender -b --factory-startup -P Art/Scripts/build_architecture.py -- --previews
powershell -File Tools/build.ps1 -Art      # runs all three, then the Unity builder
```

## Conventions

| Topic | Rule |
|---|---|
| Units | Metres, 1 Blender unit = 1 Unity unit (`apply_scale_options=FBX_SCALE_ALL`, Unity `useFileScale`). |
| Axes | Blender (x, y, z) → Unity (x, z, y), verified with an import probe. Unity importer uses `bakeAxisConversion`; static props are exported with `bake_space_transform` so nodes have identity rotation (sub-objects like the desk drawer can be animated along local axes). |
| Facing | Props: the usable front faces Blender −Y (Unity −Z). The Unity builder rotates each prop by the yaw of the person using it. Characters face Blender +Y (Unity +Z = `transform.forward`). |
| Pivot | Bottom centre (floor contact). Wall-mounted props: back centre at mounting height 0. Desk items: bottom centre on the desk top. |
| Materials | Named after `Art/palette.json`; Unity remaps them by name to URP Lit materials generated from the same palette (`SearchAndRemapMaterials`). One palette = consistent look. |
| Shading | Bevel + Weighted Normal modifiers kept live in the `.blend`, applied on export (crisp edges, soft highlights). |
| Colliders | Not authored in Blender. The Unity builder adds a `BoxCollider` from renderer bounds to furniture/stations (layer `Furniture`), wall pieces (`Walls`, blocks line of sight) and glass (`Glass`, blocks movement but not sight). Items have no colliders (positions are rules-driven, not physics). |
| Previews | `Art/Previews/` (characters, per-prop renders, overview sheets). |

## Architecture kit (`Art/Blender/architecture.blend`)

`Wall_1m`, `WallAccent_1m`, `WallWindow_2m`, `Glass_1m`, `DoorFrame_1m6`, `Pillar`, `Floor_Carpet`, `Floor_Tile`,
`Floor_Wood` (2 × 2 m), `PendantLamp`, `Skyline` (backdrop). The Unity builder lays the kit along the floor plan in
`ProjectBuilder.Scene.cs` (pieces are stretched to fit each segment), so the office layout can be edited in one place.
